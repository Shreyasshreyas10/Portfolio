# Portfolio Website - Web Technologies & Software Engineering

A modern, responsive portfolio website for showcasing your work in Web Technologies and Software Engineering courses.

## Features

- ✅ Responsive navigation bar with smooth scrolling
- ✅ Home section with call-to-action buttons
- ✅ About Me section with academic background
- ✅ Skills section with animated progress bars
- ✅ Projects showcase section
- ✅ Assignments section
- ✅ Learning journey section
- ✅ Contact form with social links
- ✅ Mobile-friendly design
- ✅ Smooth animations and transitions

## Getting Started

1. Open `index.html` in your web browser
2. Customize the content with your personal information (see details below)

## Customization Guide

Please provide the following information to personalize your portfolio:

### Personal Information
- **Student Name**: Your full name
- **Profile Picture**: URL or path to your profile image
- **Semester**: Current semester (e.g., "Semester 5")
- **Department**: Your department name (e.g., "Computer Science")

### Academic Background
- Your educational background and journey
- Current institution and program

### Passion & Interest
- Your passion for Web Development & Software Engineering
- What drives you in this field

### Skills
- **Languages**: List of programming languages you know with proficiency percentages
- **Frameworks**: Frameworks and libraries you're familiar with
- **Tools & Technologies**: Development tools, databases, and other technologies

### Projects
- Project titles
- Project descriptions
- Technologies used
- Links to live demos or GitHub repositories
- Project images (optional)

### Assignments
- Assignment titles
- Descriptions
- Links or details about your coursework

### Learning Journey
- Your learning experiences
- Coursework highlights
- Key takeaways from your courses

### Contact Information
- Email address
- Phone number
- LinkedIn profile URL
- GitHub profile URL
